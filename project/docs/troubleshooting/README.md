# Troubleshooting

- `N/A` means the source is unsupported, unavailable, or ambiguous; it is safer
  than displaying a guessed value.
- If a new executable opens Settings on an old copy and then exits, stop the old
  tray process first; all copies share a single-instance identity.
- If Start with Windows points to an old directory, disable and re-enable it
  after starting the new executable.
- For placement issues, include monitor count, orientation, DPI percentages,
  and the sequence that reproduced the issue. Do not attach a full desktop
  screenshot without redaction.
