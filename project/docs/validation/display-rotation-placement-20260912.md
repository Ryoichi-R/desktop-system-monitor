## 準備と記録

対象Surface / win-arm64、単一モニター、175%（DPI 168）、UiScalePercent 85。OS/プロセスのarchitecture、候補exeのフルパス・SHA-256・PE architecture、ソース変更のdigest、開始時刻、モニター名、作業領域DIP、ウィジェット幅/高さを今回の実行で記録する。過去の公開バイナリを新しいソースの受入に流用しない。

アプリ終了後、既存settings.jsonをアクセス制限されたローカル場所へバックアップしてから候補を起動する。既存設定を削除・初期化しない。v4が残っている場合はDR-7を最初に行う。既にv5の場合は実ユーザー設定をv4へ書き戻さず、分離した検証用ユーザープロファイルの合成v4設定で移行を検証する。旧バイナリへ戻す場合は候補を終了し、対応する元バイナリとバックアップ設定を組み合わせる。v5設定をv4バイナリに渡さない。

観測は配置キーだけを記録する: SchemaVersion、PlacementMode、PlacementAnchor、HorizontalMarginDip、VerticalMarginDip、SavedMonitorDeviceName、SavedRightEdgeDip、SavedTopEdgeDip、SavedMonitorDpi、PlacementXRatio、PlacementYRatio、SavedWorkAreaWidthDip、SavedWorkAreaHeightDip。設定ファイル全体を証跡に転載しない。

ドラッグはクリック透過を必要に応じて既存UIで解除して行い、終了後に元の設定へ戻す。ドラッグ完了後300ms以上、回転後は通知が落ち着いて2秒以上待ち、位置と保存値の安定を確認する。記録は実施時刻・実測座標・保存比率・作業領域サイズ・合否を含める。DIP誤差は0.5以内、比率は1e-6以内を目安とし、超過した場合は実測値と理由を記載してFAILまたは要調査とする。
