# Payload directory

This directory is generated by
`scripts/build-desktop-system-monitor-installer-package.ps1` and promoted by
`scripts/promote-desktop-system-monitor-installer-payload.ps1`. ZIP archives and
the generated `payload-manifest.json` are local/generated artifacts and are not
source inputs. The schema is kept with the promoted payload as
`payload-manifest.schema.json`.

Never copy a `validation-only` payload into a root one-click package. A
`local-only` payload is permitted only after the owner has recorded the Gate 0
approval and must retain the `未検証プレビュー・公開禁止` warning.
