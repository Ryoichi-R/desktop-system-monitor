# macOS版の使い方（ローカル評価版）

対象はApple Silicon Mac。動作確認機はMac Studio／Apple M5 Max／macOS 27.0。Windows版は従来のWPFを保持し、Mac版はAvalonia 12.1.3で動作します。公開配布・インストーラー・WinGetの対象ではありません。

## 起動と操作

ビルド環境には.NET SDK 10とPowerShell 7が必要です。プロジェクトディレクトリから以下を実行します。

```powershell
pwsh -NoProfile -File scripts/test-desktop-system-monitor.ps1 -Core -Mac -Avalonia
pwsh -NoProfile -File scripts/publish-desktop-system-monitor-macos.ps1 -OutputRoot <未使用の出力ディレクトリ>
```

生成されたDesktopSystemMonitor.appを開きます。AppとSensorHostを同梱したself-contained arm64アプリなので、実行先での.NET runtime導入は不要です。macOSの署名・初回起動確認はOSに従ってください。

設定は上部のメニューバーのアイコン、またはウィジェットの右クリックから操作できます。Dockにはアイコンを出しません。

- **表示倍率 → 倍率を入力…**: 50〜150の整数を入力し適用。1%単位。設定は自動保存されます。キャンセル・不正入力では変わりません。
- **表示形式**: 通常版と縮小版。ドラッグで位置を変更できます。画面の作業領域変更時は領域内へ補正します。
- **常に手前／デスクトップ最背面／クリックを透過**: クリック透過の解除はメニューバーから行います。
- **全画面時に自動で隠す**: 既定で有効。ウィジェットがある画面の最前面の通常ウィンドウが画面四辺を覆う場合、ウィジェットだけを隠します。メニューバーは残ります。「モニターを表示」で一時的に復帰し、全画面状態が解消するまで再び隠しません。自動復帰時は他アプリのフォーカスを奪いません。
- **高負荷プロセス…**: CPU使用率の上位10件とディスクI/O速度。CPUは全論理コア合計を100%とした値です。アクティビティモニタの1コア=100%とは基準が違います。権限がないプロセス、終了・再起動直後のプロセスは表示しません。
- **ディスクの読み書き…**: 取得可能な物理ディスクのI/O合計。内蔵・外付けを含みます。KB/s・MB/sは10進単位です。
- **ログイン時に自動起動**: 現在の.appの場所を登録します。次回ログインに反映し、今のアプリを起動し直したり終了させたりしません。既存の自動起動登録があれば、新版を起動したときにその場所へ引き継ぎます。無効にしていた場合は自動で有効にしません。通常は `~/Applications/Desktop System Monitor.app` を更新して使用してください。
- **診断ログを記録**: 既定無効。終了問題の調査時に有効にしてください。最大1MB×5ファイル。保存先と記録範囲は[PRIVACY](../../PRIVACY.md)を参照してください。
- **終了**: メニューバーまたは右クリックから終了できます。補助画面だけを閉じてもモニターは継続します。

## 表示値と制限

CPU・メモリ・ネットワーク・GPU使用率・ディスクI/O・高負荷プロセスをSensorHostで取得します。CPU／GPUの温度に付く`*`は関連センサー群の最大値による推定です。温度はMac17,14／macOS 27.0の固定プロファイルに限定し、OS・機種不一致や10%超のセンサー欠落はN/Aにします。GPU電力はGPU Energyを2サンプル平均で表示します。

CPU電力・CPU現在周波数・GPUメモリ・ディスク稼働率は対応済みの値として表示しません。Windowsの専用VRAMやprivate bytesをMacの統合メモリ／physical footprintへ読み替えません。ディスク選択・容量表示もこの増分には含めません。

取得失敗・Host終了時はN/Aとし、古い値を維持しません。再接続にはbackoffと連続失敗上限があります。上限到達時はアプリを再起動します。

全画面判定は権限昇格を伴わないウィンドウ形状の近似です。通常の最大化は除外しますが、メニューバーを隠した特殊なボーダーレス画面は全画面と判定し得ます。取得できない場合は表示へ戻します。複数画面・通常Space切替は利用者指定で実機確認をスキップしています。

長時間利用、スリープ復帰、ログイン時自動起動、他監視アプリとの精度照合は[受入表](../validation/macos-final-acceptance.md)で確認します。macOS 27固有の対応制限と、先行版での原因未特定の終了報告は残ります。
