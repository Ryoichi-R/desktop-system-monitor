# Security policy

## Supported versions

Version `0.1.0` is a source-only experimental preview. The repository owner
handles security reports on a best-effort basis. No response or remediation
deadline is guaranteed, and there is no supported prebuilt binary.

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities or exposed secrets.
Use this repository's **Security → Report a vulnerability** flow when it is
available. Do not put suspected secrets, credentials, or exploit details in a
public issue. If the private flow is unavailable, contact the repository owner
through an already established private channel; no public fallback address is
claimed.

Include the affected version, architecture, impact, and minimal reproduction.
Remove credentials, usernames, device names, process lists, and unrelated logs.
Acknowledgement and remediation are best effort and depend on owner
availability, severity, and reproducibility.
