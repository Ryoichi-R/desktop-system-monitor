# macOSのトラブルシューティング

- **Dockにない**: 常駐アプリのため正常です。上部メニューバーのアイコンから操作します。
- **ウィジェットだけ消えた**: 全画面時の自動非表示か、背面配置を確認してください。メニューバーの「モニターを表示」で復帰できます。「全画面時に自動で隠す」を解除して切り分けできます。
- **メニューバーも消えた**: アプリが終了した可能性があります。再起動後「診断ログを記録」を有効にして、再発時刻を記録してください。ログはPRIVACY記載のフォルダーにあり、完全なスタックや識別情報は含みません。先行版の90%変更後の終了報告は、変更操作だけでは再現せず原因未確定です。
- **設定画面を閉じた**: 補助画面を閉じても本体は終了しません。本体の「終了」は全補助画面を閉じます。
- **CPU/GPU温度がN/A**: 機種・OSプロファイル不一致、読み取り不能、センサー欠落が考えられます。CPU電力・GPUメモリなどは未対応です。値を0と解釈しないでください。
- **一時的に指標がN/A**: SensorHost再接続時は準備中を経て復旧します。再起動上限に達した場合はアプリを再起動します。
- **ログイン時に古い版が起動する**: 修正版の.appを起動すると、既存の自動起動登録をその場所へ引き継ぎます。登録が無効・破損している場合は「ログイン時に自動起動」を有効にしてください。登録はアプリの絶対パスに紐づくため、通常は `~/Applications/Desktop System Monitor.app` を更新して使用します。
- **ログイン直後や画面変更で位置がずれる**: 画面内へ一時補正しても保存済みの希望位置を保持し、画面が戻ると再適用します。ドラッグ操作では希望位置を更新します。過去の版で上書き済みの位置は復元できないため、一度希望位置へ移動してください。
- **別の監視アプリと数字が違う**: CPUの分母、採取間隔、メモリ定義、GPUカウンターの競合を確認します。高負荷プロセスのCPUは全コア合計100%、温度はセンサー群の推定最大値です。

問題報告では操作・発生時刻・メニューバーが残るかを伝えてください。個人情報を含む全画面画像をそのまま保存・共有しないでください。
